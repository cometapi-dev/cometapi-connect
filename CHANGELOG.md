# Changelog

This file records user-visible CometAPI Connect releases. Development work between releases is tracked in Git history and pull requests.

## [0.1.3] - 2026-09-29

First CometAPI-maintained release.

- Connect supported AI applications to CometAPI through a local browser interface.
- Preview, apply, repeat, and safely restore application configuration changes.
- Protect credential-bearing files from writes when Git tracking cannot be verified safely.
- Include Windows x64, macOS universal2, and Linux x64 standalone builds.
- Include 16 interface languages and bundled third-party license notices.

This release contains unsigned development builds. The macOS build is not notarized. See the release metadata and [security policy](SECURITY.md) before installation.

## [0.1.3.dev10]

Internal development release retained for provenance. Use `v0.1.3` for the stable release entry point.
